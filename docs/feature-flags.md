# 기능 플래그

`features.json` 은 이미 설치된 모든 Wooi 에 **앱 재배포 없이** 기능을 여닫는 스위치다.
파일을 `main` 에 커밋하면 30분 안에 모든 설치본이 가져간다 — 커밋이 곧 배포다.

```json
{
  "remoteAccess": false
}
```

## 왜 공지와 파일을 나눴나

배달 경로는 같지만 성격이 다르다. 공지(`notice.json`)는 사용자에게 보이는 일시적 메시지이고,
플래그는 운영 상태다. 바꾸는 주기도, 검토 기준도, 잘못됐을 때의 결과도 다르다. 한 파일에
두면 플래그를 고치다 공지를 건드리게 되고, 스키마 문서도 둘 다 흐려진다.

## `remoteAccess`

원격 접근(모바일 컴패니언) UI 를 열 것인가.

데스크톱이 먼저 나가고 폰 앱은 스토어 심사를 거쳐 나중에 올라간다. 그 사이에 켤 수 있게
두면 사용자는 페어링 QR 만 보고 막힌다 — 상대가 아직 존재하지 않는다. 폰 앱이 올라가는 날
이 값을 `true` 로 바꿔 커밋하면 그것이 곧 활성화이고, 데스크톱은 다시 내보내지 않는다.
문제가 생기면 같은 방법으로 즉시 닫는다.

닫히는 방향이면 이미 켜져 있던 연결도 끊긴다. 잠갔다고 말해 놓고 계속 붙어 있으면 잠근 것이
아니다.

## "모른다"와 "꺼짐"은 다르다

값이 없거나 boolean 이 아니면 앱은 **모른다**로 취급하고 마지막으로 확인한 값을 그대로 쓴다.
파일을 못 가져온 것을 꺼짐으로 읽으면, 오프라인이 된 순간 이미 쓰던 사람에게서 기능이
사라졌다 나타났다 한다.

## 플래그보다 먼저 써야 할 때

만드는 사람은 스토어에 올라가기 전에도 써야 한다. 로컬 탈출구가 있다:

```sh
touch "$HOME/Library/Application Support/Wooi/remote-access.enabled"
```

파일의 **존재**만 본다(내용은 읽지 않는다). 설정 파일이 아니라 별도 파일인 이유는, 설정은 앱이
주기적으로 통째로 덮어써서 앱이 켜져 있는 동안 고치면 지워지기 때문이다.

로컬에서 플래그 자체를 시험하려면 `WOOI_FEATURES_URL` 로 다른 엔드포인트를 가리키면 된다.
